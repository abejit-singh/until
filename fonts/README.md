# Fonts

The typefaces used by the site, served from here so that no request goes to a font service.

| --- | --- | --- |

| JetBrains Mono | Copyright 2020 The JetBrains Mono Project Authors | https://github.com/JetBrains/JetBrainsMono |
| Space Grotesk | Copyright 2020 The Space Grotesk Project Authors | https://github.com/floriankarsten/space-grotesk |

All of them are licensed under the SIL Open Font License, Version 1.1 (see `OFL.txt`). The files are the ones distributed by Google Fonts, split by script: `latin` covers English and Western European languages, and the other files are downloaded only if a page shows text in those alphabets. `css/fonts.css` declares them.
